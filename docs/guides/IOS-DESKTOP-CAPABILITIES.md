# iPhone USB 能力清单

本次运行平台为 Windows x64。验收手机为 iPhone SE（第三代），iOS 18.6.2；其他 iOS 版本以连接和具体操作结果为准。macOS 尚未实现或验收。

手机需要信任电脑并开启开发者模式，电脑使用已有 Apple USB 支持组件。控制、截图均走 USB，不安装手机辅助 App，不使用 AirPlay、Wi-Fi、蓝牙或采集过滤驱动。首次开发者支持文件准备可能联网，使用 pymobiledevice3 的用户目录缓存。

| 类别 | 已实现操作 | 范围 |
| --- | --- | --- |
| 画面 | 查看、等待、历史截图、连续截图预览 | 仅 `main` 真实主屏；预览不产生模型观察编号 |
| 触摸 | 点击、双击、长按、滑动、拖拽、放大、缩小 | 原始截图像素坐标；仅正向竖屏输入 |
| 文字 | 中文及其他文字输入、全选、删除 | 临时剪贴板按系统版本号核对后恢复；用户期间复制的新内容不会被覆盖 |
| 按键 | 主页、最近任务、回车、删除、向前删除、方向键 | 没有 iOS 通用返回键 |
| 应用 | 列表、基础详情、按 Bundle ID 启动、终止进程 | 启动前先查看 `main`，传递最新观察编号；启动不等于业务完成 |
| 剪贴板 | 读取、写入、清空文本 | 显式工具保留用户要求的修改 |
| 文件 | 列表、属性、名称搜索、UTF-8 文本读写、创建目录、复制、移动、重命名、删除 | 仅 AFC 媒体目录，不包含任意应用私有文件；覆盖、递归需明确参数 |
| 公共工具 | 搜索、网页读取、记忆、提问、任务状态 | 与现有桌面和手机公共实现共用 |

不注册：虚拟屏、无障碍节点、结构化通知、联系人、日历、短信、通话记录、媒体库、闹钟、系统面板，以及未实现的应用管理操作。iOS 不声明 Android 式全局应用禁止策略。横屏和倒置竖屏仅可观察，不开放输入。

队列绑定提交时的设备与配置版本，存在任务或等待队列时不能换设备。STOP、人工接管、控制权代次、动作去重及租约由宿主和执行器统一核对。连接恢复、程序重开均不自动重跑。输入派发与截图观察分别报告，截图失败不会抹掉已知派发事实。

预览目标为 15 FPS，使用单个在途截图请求和最新帧，不积压补帧。实际帧率受画面复杂度、USB 吞吐及电脑负载影响，详见本次验收报告。收起侧栏、最小化或隐藏窗口时停止预览采集，模型主动观察仍可独立进行。
