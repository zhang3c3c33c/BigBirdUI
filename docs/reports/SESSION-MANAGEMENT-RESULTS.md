# 侧边栏会话管理与任务排队验收

2026-09-26。已构建并覆盖安装到 vivo V2366GA（Android 16 / API 36）。本轮只使用本地模拟模型；没有请求用户配置的外部模型 API。

## 已实现

- assistant-ui 的 ExternalStoreThreadListAdapter 与会话列表组件；窄屏抽屉、宽屏常驻，标题搜索、新建、切换、重命名、确认删除。
- 浏览会话与运行会话独立。全局执行提示支持返回运行会话、预览和停止；后台回复不改变当前查看的会话。
- Android 服务持有全局 FIFO 队列，提交编号去重；同一会话可连续排队。等待项不写入 Pi 上下文。首次提交生成并持久化前 24 个 Unicode 字符标题。
- 正常本轮结束且执行通道释放后继续下一项；STOP、接管、锁屏、模型和执行通道错误暂停队列。进程恢复保持暂停，中断的领取不会自动重放。
- 每会话独立展示缓存、任务记录、草稿、阅读位置及分页窗口。新任务显式指定 Pi 会话并恢复历史，使用当时的全局模型配置。
- Pi SessionManager 管理原始 JSONL、标题、分支和历史；目录命令可以在无模型配置、无手机连接时工作。完整分支历史包含压缩前消息。浏览历史不切换正在运行的 Pi。
- 删除仅作用于对应私有会话文件、缓存和等待项。当前会话删除后选择相邻会话；没有剩余会话时创建空会话。

## 关键集成修复

- Android 私有目录的 `/data/data` 与 `/data/user/0` 别名会让按 cwd 查询漏掉旧会话；改用私有目录的 `SessionManager.listAll`，不重写旧文件。
- Pi 的打包 RPC 入口接管标准输出；自定义目录回包必须使用接管前捕获的协议 writer，并等待写入回调。独立导入 output-guard 不足以共享 bundle 内部状态，已用 APK 的实际 ZIP 回归覆盖。
- 执行切换前同步关闭旧 runtime 的目录派发；STOP 清理期间占用执行器，避免绑定尚未退出的进程。
- 持久化失败会暂停；只有明确尚未调用 start 的领取可退回队首。调用 start 前同步标记不可回退，避免保存回调竞争造成重放。
- 长历史切换在消息 DOM 恢复后还原滚动位置；小屏等待项列表限制高度，输入框保持可见。
