# 设置与输入区模型选择验收

2026-09-27。三名子代理实施；主代理固定接口、集成审查、构建与操作真机。

## 已实现

- 侧栏设置入口打开独立原生页面，采用 AndroidX Preference；分类为模型与 API、手机权限、界面、帮助与诊断。
- 支持多个连接及每连接多个模型，三种协议：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。连接编辑是原生页面，支持供应商预设、默认模型和能力说明。
- 输入框上沿选择当前会话模型与思考档位；模型面板按连接分组。复用当前 Pi 版本的能力目录和档位，未知能力不标作已验证，无可调档位时隐藏入口。
- 每会话保存选择；排队时冻结连接版本、模型与档位，正在运行的请求不受切换影响。续接使用任务所属会话的选择。未明确设置档位时继承原有 Pi 设置，明确设置通过 Pi CLI 校验与应用。
- 旧单连接迁移到现有 Keystore 加密文件中的多连接 registry，历史版本也只保存在加密文件。WebView 只接收非敏感选择元数据；密钥不进入 Bundle 或普通 Preferences。
- 选择和发送都在持久化成功后确认；失败保留草稿。删除连接不把引用它的排队项静默改到其他供应商。
- 用户明确点击后可测试已保存模型，复用 Pi ModelRuntime 适配器发送固定文字、已声明图片能力时的合成像素及模拟工具往返；没有手机工具、Agent 循环或会话历史。测试结果仅代表本次请求。
- 悬浮控制条偏好、权限状态及授权结果刷新。设置页和聊天页沿用现有暖白/绿色风格。

不提供尚未实现的深色模式、分辨率预设、缓存清理等占位开关。“关闭服务”暂不显示，因为仍有 Activity 绑定时 stopSelf 不等于资源已释放。
