# 简洁聊天界面改造

2026-09-26

- 移除原生重复顶栏，主页面只保留会话标题、进度和画面入口。运行时有一条执行状态及 STOP，浏览其他会话时可返回执行会话。
- 会话抽屉只放会话管理和底部设置。继续复用 assistant-ui 的会话适配器。
- 任务进度按需打开，展示实际目标、步骤、结果和待回答问题。内部约束/事实不铺在聊天上方；常规 task_state 记账调用不占聊天步骤，失败仍可见。
- 全局等待数量与暂停/继续位于输入框上方，仅有等待项时出现。点数量打开有序全局队列，可进入会话或取消等待项。当前会话等待消息保留在输入框上方。
- 正文和执行说明直接可见，思考默认折叠。移除重复边框和背景，保留实际工具意图和结果状态。
- 执行画面保留原生 SurfaceView，手机全屏、宽屏右侧并列；返回关闭画面不会停止任务。接管、继续、STOP 保留。WebView 失败时显示原生紧急停止。
- scrcpy 虚拟显示设为 1080×2160 / 480 dpi，即竖屏 18:9（宽高 1:2）。预览和触摸沿用实际视频尺寸的等比映射。

## 统一视觉样式

聊天、侧边栏、进度/队列面板、原生设置、执行画面和悬浮控制条统一采用暖白底、绿色操作色、轻边框和圆角。原生控件通过 UiStyle 和 Theme.BBUI 复用，不依赖额外 UI 框架。停止使用红色，不再显示默认灰色凸起按钮。执行空间空白页只保留 BBUI 标识。
