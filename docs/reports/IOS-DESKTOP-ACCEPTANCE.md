# iPhone USB 桌面接入验收记录

日期：2026-09-29。运行平台：Windows x64。真机：iPhone SE（第三代）、iOS 18.6.2、750 × 1334；Android 回归设备：vivo V2366GA、Android 16。

## 结论

USB 控制、连续截图预览、能力过滤、公共聊天与队列、人工接管和明确恢复已实现，功能回归通过。没有安装手机辅助 App，没有修改 Apple 驱动，没有引入 AirPlay 或 QuickTime 采集组件。

**性能验收未全部达标**：触摸测试应用五分钟测试中，动态阶段新帧提交约 12.01 FPS；系统设置页滚动约 10.08 FPS，未达到动态场景至少 12 FPS 的要求。15 FPS 是采集目标，不是实际稳定帧率。现版本应作为功能预览版，不标记为全部验收通过。

- 应用列表、详情、按 Bundle ID 启动与终止进程通过。应用启动要求最新主屏观察，不将启动回执等同于任务完成。
- 手机文本剪贴板读取、写入、清空通过。AFC 可访问区域内的列表、属性、搜索、文本读写、建目录、复制、移动、重命名、删除通过；独立测试目录已删除，原剪贴板已恢复。

- 实际 USB 拔插后不会自动重连执行任务；明确恢复后保留 STOP，并可只读观察。执行器异常退出后确认旧进程结束、租约释放，再显式建立新执行器。

## 预览性能

测量来自实际 Electron 页面；新帧编号提交与图片解码事件分别计数。相同画面内容可能不触发新的图片加载事件，不能将提交次数直接宣称为可见变化次数。

| 场景 | 时长 | 新帧提交 FPS | 变化图片加载 FPS | 帧间隔 P95 |
| --- | --- | --- | --- | --- |
| 触摸测试应用静态段 | 约 20 秒 | 13.73 | 静态不适合此指标 | 82 ms |
| 触摸测试应用持续触摸段 | 约 280 秒 | 12.01 | 10.97 | 108.6 ms |
| 系统设置页静态段 | 约 6 秒 | 12.18 | 静态不适合此指标 | 97.5 ms |
| 系统设置页往返滚动 | 约 24 秒 | 10.08 | 9.88 | 124 ms |

五分钟总测试约 300.8 秒。动态段无请求失败，最大帧间隔约 323 ms；单请求在途、只保留最新帧，没有建立补帧队列。复杂主屏早期原始截图基线约 3.6 FPS，表明不同页面的 PNG 传输成本差异很大，不承诺各页面达到表中最佳结果。

实际鼠标结束拖动到 Electron 解码出变化像素的 8 次测量为约 319–637 ms。这不是 HID 写入耗时。五分钟中进程树平均 CPU 约 0.63 个核心；各进程工作集之和约 809 → 805 MiB，没有持续总量增长（共享页可能被重复计算，不代表唯一物理内存）。

侧栏收起与窗口最小化停止预览采集的检查通过。模型主动观察独立于预览编号，操作后的模型观察强制取得新截图。性能数据保存在本机忽略目录，不将手机截图、身份或配置写进发布包。

## 发布与边界

依赖锁定为 pymobiledevice3 9.34.0、pmd-pytcp 0.0.6、pytun-pmd3 3.0.3，使用打包的 Python 3.12、Node、Pi；版本清单及第三方许可随包提供。开发者支持文件首次准备可能联网，缓存于 pymobiledevice3 的用户目录。运行时不依赖 BigBirdTouch 或仓库中的测试文件。

运行中锁屏不会自动解除 STOP。一次 Python Windows socket 关闭回调出现 WinError 10054；已记录，正常进程退出由操作系统回收句柄，不将该回调当作输入重试理由。退出清理有总时限，未确认清理会明确报告。

不支持的能力见 `IOS-CAPABILITIES.md`；只开放正向竖屏输入。其他 iOS 版本、macOS、真实云 API、首次从空缓存下载开发者镜像尚未完成真机验收。

### 独立发布包检查

ZIP 已通过所有条目的 CRC 检查，并解压到仓库外 Windows 临时目录中的中文、空格路径。实际启动解压后的 `BBUI.exe`，没有使用开发目录中的 Electron 可执行文件。

- 从独立样例导入旧配置及 Pi JSONL 会话，原文件逐字节保持不变；旧配置无平台字段时仍视为 Android。
- 正常退出并重开后，导入会话、选择状态、配置仍保留；系统加密凭据能解密且没有明文落入 settings.json，渲染层仍只收到密钥存在标记。任务保持暂停且没有自动重跑。此项验证现版本数据格式的重开保留，没有用用户真实目录做覆盖升级。
- 使用包内 Node、Python、Pi 和 USB 后端完成 iPhone 本地模拟模型工具调用、预览、人工操作、收起与最小化暂停。20 秒功能复验中新帧提交约 12.24 FPS；该短测不替代上面的五分钟性能验收，也不改变复杂页面未达标的结论。
- 同一发布包连接 vivo，完成预览、人工点击和结束接管；未修改用户 Android 应用数据。
- 正常关闭后，仓库外解压目录所属的 Electron、Node、Python 进程全部退出；iPhone 设备租约可重新取得并释放。

验收用测试数据保存在独立目录；没有迁移或改写用户正在使用的旧电脑版数据。最终 ZIP 附 `.sha256` 文件，功能清单、验收报告、版本清单和第三方许可位于 `resources/app/`。

## 统一断线恢复复验（2026-09-29）

Android/iPhone 控制断开后立即暂停并中止模型，最多自动重连原设备 3 次；成功保留会话并保持暂停，失败回欢迎页。预览失败仅在画面区域提示。等待队列允许重连原设备，用户停止/关闭取消重试，输入从不自动重放。

Python 154 项、桌面 90 项、Pi 15 项、前端契约 18 项、桌面浏览器 8 项及 TypeScript 检查通过；真实 Pi/本地模拟 API 集成与 Android 构建通过。两台真机均在实际 Electron 页面运行本地模拟模型请求时中断自有执行器，确认自动重连、新预览、原会话、草稿及暂停队列保留，模型请求总数仍为 1。3 次连续失败和取消通过模拟测试验证；本轮没有重复物理拔线测试或调用真实云 API。详见仓库 `docs/reports/DESKTOP-RECONNECT-RESULTS.md`。
