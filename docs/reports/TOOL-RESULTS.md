# 工具职责改造验证

日期：2026-09-26。对应契约：`docs/contracts/TOOL-CONTRACT.md`。安卓、桌面统一工具和旧 MCP 均已落实；手机已覆盖更新，已有配置、密钥、Pi 历史和权限保留。

## 行为变化

- 执行状态、观察结果和通道状态分离；正常中间页、业务拒绝、前置校验失败不终止健康执行连接。
- 动作后的截图失败保留已知派发事实；重复请求保留原动作事实且不重放。
- 应用启动一次后返回实际前台和画面，分身选择器不再被当作致命启动失败。
- 用户明确逐项批准后，移除密码类型的一刀切输入禁令、固定像素阈值硬拒绝和目标应用必须立即前台的任务终止规则。输入焦点、显示屏/用户/坐标身份、有效观察、用户 STOP、用户配置范围及去重仍保留。
- 模型继续决策；工具无固定 100 次调用中断和购物/验证码一律接管等任务政策。
- 安卓 schema 只声明 16 个实际操作，生命周期由宿主管理；应用查询支持筛选、多入口和可取得的名称，屏幕查询返回真实前台。
- 桌面可同屏跨应用，创建屏幕与启动解耦；旧 MCP 不再向模型暴露清除 STOP 的 resume。
- 真正传输未知隔离新输入但保留可用观察；桌面用户命令 `/phone-recover` 校验进程退出与租约后恢复，安卓由宿主新任务重建异常连接；均不自动重放或清除用户 STOP。
- 工具卡片展示派发/观察事实，取消调用返回即成功的勾选；部分派发不会伪装为完整完成。
