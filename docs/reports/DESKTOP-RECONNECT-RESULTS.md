# 桌面端断线恢复验收（2026-09-29）

## 行为

- 预览读取失败只在手机画面区域提示并重试，不因此切换欢迎页。
- 控制连接断开立即暂停会话和队列、中止模型、撤销人工操作权限；清理旧执行器后，对同一设备最多自动重连 3 次。
- 重连期间保留聊天、草稿和阅读位置，显示“正在重连 n/3”；历史、复制和停止仍可用，输入派发和继续任务被禁用。
- 恢复必须取得新观察，成功保持暂停，不重新发送已派发操作；失败回欢迎页，复用原有状态文字和“连接手机”入口。
- 等待队列存在时可以重连原设备，不能换设备。用户停止或关闭窗口取消后续重试。若旧进程或租约释放不能确认，不绕过清理创建第二个执行器。

## 主代理审查

审查并修正了以下问题：失联后等待手机停止回执才中止模型；执行器已退出却因收不到 HTTP 清理回执无法恢复；恢复读取失败仍可能被判定成功；宿主中止 Pi 所产生的 `/cancel` 误取消自身重连；ADB 专有连接异常漏分类。

预览/截图/方向读取错误、业务拒绝与控制传输错误分别报告。动作已派发后截图失败仍保留派发事实，所有恢复均不重放输入。
