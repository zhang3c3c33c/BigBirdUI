# 会话自动命名

2026-09-29。Android 与 Windows 共用 `pi/android/session-title.mjs`，复用现有 Pi 模型适配器，不新增模型工具或设置项。

## 行为

- 新会话首次消息成功保存后，使用该次提交绑定的模型在后台尝试一次命名。输入只有首条消息的有限文本，没有截图、工具记录或完整聊天历史。
- 提示词概括用户目标，沿用用户语言，中文建议 8～16 字。标题不会写入正文消息历史。
- 手动改名优先，包括改成原有文字；删除、退出和过期响应不会覆盖用户选择。失败保留原有标题，不自动重试。
- 旧会话没有自动命名资格，不批量请求模型或改写名称。重启不会补发已尝试的命名请求。
- Windows 使用独立目录工作进程；Android 复用唯一 Node 运行时，命名请求不占设备执行队列。模型请求复用 Pi，平台仅负责持久化和运行时生命周期。

## 审查发现

- 将一次命名资格绑定到成功持久化的提交，避免前一个保存失败吞掉后一个提交的资格。
- 标题写入与执行器切换协调，避免目录写入和活跃 Pi 会话互相覆盖。
- 手机模拟任务使用独立派生配置目录，避免真机验收改写用户模型配置和偏好。
- 真机模拟服务显式以 UTF-8 解码 JSON；NanoHTTPD 默认按 ASCII 解码时，会把中文命名指令误判成普通聊天。
