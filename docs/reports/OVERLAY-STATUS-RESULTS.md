# 后台任务状态胶囊

2026-09-29。用户确认以状态提示为主，子代理实施，主代理集成审查与设备验收。

## 产品与实现

- 鸟形标志、一行真实状态/当前工具意图、独立停止区域；没有展开面板、接管、继续、关闭菜单。
- 点击主体返回正在执行的会话；待回答时定位原问题，既不聚焦键盘也不提交答案。导航不改变执行位、队列或虚拟屏控制权。
- 胶囊高 48dp，宽约半屏，180–240dp；沿用应用品牌色、圆角和原生图标，长意图省略。
- 拖动吸边，保存左右边和相对高度；拖动越过触摸阈值即取消子控件点击，独立 STOP 去重。
- 默认屏 BBUI Activity 在前台时隐藏；后台任务、等待回答、人工控制时显示。空闲虚拟屏不常驻；停止、异常和本轮结束短暂保留 3 秒，普通事件不会延长结束提示。
- 设置、悬浮权限、Shizuku、锁屏共同限制显示。隐藏仅改变呈现；STOP 和锁屏继续走原有执行中止与队列暂停流程。
- 复用既有 WindowManager、服务、ChatStore 工具意图和任务状态；没有引入另一套窗口服务、WebView 或轮询。只有终态一次性定时关闭，以及附加失败最多三次有界重试。

## 审查修正

- 窗口附加/布局失败后加入 200/800/2000ms 有界重试；隐藏、权限丢失、销毁取消重试，不触发手机动作。
- 旋转前尚未完成的会话导航保存恢复；问题定位完成向原生回执，避免页面重建再次跳到旧问题。
- 第一轮真机拖动失败：局部 Insets 更新取消手势并回到旧锚点。修正为局部通知只触发重算，拖动期间维持手势；全屏几何来自 WindowMetrics，MOVE 限制到可用区域，UP 吸边保存。
- 第二轮真实键盘验收发现 NOT_FOCUSABLE 单独使用时收不到 IME 变化。按 [Android 官方窗口与键盘说明](https://developer.android.com/develop/ui/views/touch-and-input/keyboard-input/visibility) 增加 FLAG_ALT_FOCUSABLE_IM，仍不抢输入焦点，不读取其他应用内容；第三轮键盘避让和原位置恢复通过。
