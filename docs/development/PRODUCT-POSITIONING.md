# 产品定位与介绍约定

项目全名为 **BigBirdUI**，中文名称为 **大鸟手机助手**，简称 **BBUI**。对外首次出现时使用全名与中文名称；已有文件名、包名和程序路径沿用实际名称。

大鸟手机助手面向用户的定位是：**帮你操作手机的 AI 助手**。公开介绍以用户目标、手机操作和任务执行体验为主线。

## 参考方向

维护者指定 [豆包手机助手官网](https://o.doubao.com/) 为产品介绍的参考。2026-09-29 查阅的页面围绕屏幕理解、任务执行、系统工具与个人记忆介绍能力。BBUI 借鉴这种从场景与用户价值出发的表达，用自己的实现和验收结果支撑具体描述。

## 对外支持范围

- Windows 桌面应用：通过 USB 连接 Android 或 iPhone，在电脑上发起任务、查看进展与人工接管。
- Android 本地应用：通过 Shizuku 授权，在手机上配置模型并执行任务。

Pi 是应用内 Agent 运行时的一部分，MCP 是内部通信与调试实现的一部分。独立 Pi 命令行、MCP 客户端接入和旧 CLI 不作为对外使用方式；相关资料放在开发文档中。

## 介绍顺序

先说明产品能帮助用户操作手机，再展示自然语言任务场景、执行进展与接管体验，随后按“Android 本机使用、电脑连接 Android、电脑连接 iPhone”三个场景给出使用教程，最后鸣谢实际使用的开源项目。源码构建、技术栈、协议及测试细节放在后面或链接到开发文档。

任务示例用于展示如何表达需求，不代表每个应用、设备和完整业务流程都已验收。平台能力分别声明；iPhone 只有真实主屏，不能套用 Android 虚拟屏和系统工具的描述。

## 描述依据

可围绕已有实现介绍看图操作、多步骤及跨应用任务、系统工具、任务队列、会话、个人记忆和模型配置。隐私说明应明确相关任务内容会进入用户配置的模型或搜索服务，不能将本地保存等同于全程离线。

语音唤醒、专用 AI 按键、锁屏执行、硬件合作及服务商生态接入不是从参考产品继承的 BBUI 能力。只有完成相应实现与验证后才加入产品介绍。项目自有代码以 MIT 许可证开源，当前为开发预览；源码公开不代表正式安装包或全部设备兼容性已验收。
