# 维护约定

## 代码位置

| 目录 | 职责 |
| --- | --- |
| `android/` | Android 应用、设备服务与原生运行时 |
| `android/chat-ui/` | 两端共享聊天界面 |
| `desktop/` | Windows Electron 宿主、设备连接与任务队列 |
| `pi/` | 两端共享 Agent、模型配置、会话与工具协议 |
| `bbui/` | Python Android / iOS 执行器 |
| `scripts/` | 构建与打包 |
| `tests/` | 回归测试及必要的安装包验证 |

Pi 和 MCP 是应用内部组件，不提供独立 CLI 或 MCP 客户端使用方式。`pi/skills/` 是应用实际加载的运行资料，应随源码保留。

## 执行器边界

工具执行明确操作并报告事实，模型根据任务和当前观察决定下一步。

- 保留最新观察校验、动作去重、设备所有权及屏幕 / 坐标身份。
- 分别报告派发、观察和连接状态；截图失败不能抹去已知派发回执，业务拒绝不代表连接断开。
- 用户 STOP 与人工接管优先；结果不确定时先观察，不能自动重放或恢复输入。
- 只声明后端实际实现的能力；保留用户配置的限制，不在执行器中写入固定任务预算或以目标包名判定任务成功。
- 断线、重开与切换设备后不能自动重跑旧任务；凭据不能进入渲染层、日志、会话或提交记录。

共享聊天界面只显示宿主状态，不持有凭据、不直接请求模型或执行工具。Android 内嵌 Node 每个 Agent 进程只运行一个实例；重启前先停止设备输入并结束旧运行时。设备服务的屏幕观察与控制通道由宿主管理。

## 修改与提交

遵循现有 Python / TypeScript 风格，保留工具协议中的中文键。行为变更补充相关回归测试，验证命令见 [构建说明](BUILD.md)。避免无关重构。

提交说明问题、行为变化与验证结果；报告中不带密钥、设备身份、私人截图或完整会话。

公开内容遵循“非必要不开”：保留使用、构建、必要维护和许可所需材料。研究、备选设计、历史报告与一次性诊断留在被忽略的本地 `runs/`，不写入仓库或安装包。
